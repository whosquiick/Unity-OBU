# Security Bootstrap sample

1. In Package Manager, find Unity OBU → Samples → Security Bootstrap → Import.
2. Open the sample scene, or drag `OBUSecurityBootstrap.prefab` into your first-loaded scene.
3. Open Tools → UnityOBU → Settings and configure keys / expected package name before building.

The prefab runs the configured probes on Start. With the default LogOnly response it will only write to the console when something trips.
